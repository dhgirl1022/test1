# iMONNIT ダッシュボード

iMONNIT APIと連携したセンサー監視・可視化Webアプリケーションです。

---

## 必要環境

- Node.js 18 以上
- npm 9 以上

---

## セットアップ・起動手順

### 1. リポジトリをクローン

```bash
git clone https://github.com/dhgirl1022/test1.git
cd test1
```

### 2. 依存パッケージをインストール

```bash
npm install
```

### 3. 開発サーバーを起動

```bash
npm run dev
```

ブラウザで http://localhost:5173 を開いてください。

---

## 使い方

### テストモード（APIキーなしで試す）

1. 起動後、API接続設定画面が表示されます
2. **「テストモードで試す（デモデータ）」** ボタンをクリック
3. デモデータでダッシュボードの全機能を確認できます

### 本番モード（iMONNIT APIキーを使う）

1. [iMONNITアカウント](https://www.imonnit.com) にログインし、APIキーIDとAPIシークレットキーを取得
2. API接続設定画面に入力して **「接続する」** をクリック
3. 接続確認後、ダッシュボードが表示されます
4. APIキーはブラウザのlocalStorageに保存されます（次回以降は入力不要）

## コンセプト — 数字ではなく「直感的なイメージ」で

数値やグラフを読む前に、状態がひと目で分かることを重視しています。各センサーは現実の計器を模した直感ビジュアルで表示されます。

| センサー | ビジュアル表現 |
|---|---|
| 温度 | 縦型サーモメーター（水銀が状態色で立ち上がる） |
| 湿度 | 円形リング + 中央の水滴が水位まで満ちる |
| ドア／窓 | ドアが実際に開閉するアニメーション |
| 人感 | レーダーが回転・パルスが広がる |
| 漏水 | トレイに水位が上がり波打つ |

状態色がそのまま情報になります：🟢 正常 / 🟡 注意 / 🔴 異常 / ⚪ オフライン。

## 主な機能

| 機能 | 説明 |
|---|---|
| 現場ビュー | 現場全体の状態エンブレム + センサーを直感ビジュアルのタイルで一覧 |
| 間取りビュー | 平面図にセンサーを**ドラッグして実際の設置場所に配置**（配置はブラウザに保存） |
| センサー詳細 | 大きなビジュアル + サーモメーターの点線を**ドラッグして閾値を調整**、過去24時間の推移 |
| アラート | 閾値超過・電池残量低下などの通知一覧 |
| ゲートウェイ | 各ゲートウェイのオンライン状態確認 |
| 拠点絞り込み | 複数拠点（ネットワーク）をワンタップで切替 |
| 自動更新 | 30秒ごとにデータを自動取得（トグルで切替） |

│   ├── api/
